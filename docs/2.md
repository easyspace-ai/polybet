1. 高水位线更新逻辑缺陷 (核心问题)
文件: server/internal/service/risksvc/risksvc.go:201-207
mark := maxCentsRatchet(bidCents, askCents)
if mark > hw {
    hw = mark
    // ...
}
问题: 使用 max(bid, ask) 更新高水位线是错误的。
在 Polymarket，每个结果（YES/NO）有独立的买卖价：
bid = 当前结果买价（你能卖出的价格）
ask = 当前结果卖价（你能买入的价格）
对于 YES 仓位，高水位应该只用 bidCents（你能变现的价格），而不是 max(bid, ask)。因为 ask 可能高于 bid，导致高水位虚高，进而抬高止损线，使得本应触发的止损无法触发。
